## О проекте

Рабочее пространство сессии. Файлы проекта добавляются по мере разработки.

## Структура

```
.
├── .editorconfig   # Единые правила форматирования
├── .gitattributes  # Нормализация переводов строк
├── .gitignore      # Исключения из индекса
├── LICENSE         # MIT
└── README.md
```

## Быстрый старт

```bash
git clone https://github.com/<owner>/intensiv-project.git
cd intensiv-project
```

## Contributing

1. Создайте ветку от `main`: `git checkout -b feat/short-description`
2. Вносите изменения небольшими логическими коммитами
3. Отправьте ветку: `git push -u origin feat/short-description`
4. Откройте Pull Request
